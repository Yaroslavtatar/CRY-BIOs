📋 CRY BIOS — ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ НА COOLIFY (bio.cryteam.ru)
========================================================================================

Данное руководство содержит подробное расписание и параметры запуска сервиса CRY BIOS
через панель управления Coolify или Docker на вашем сервере.

----------------------------------------------------------------------------------------
1. ОСНОВНЫЕ ПОРТЫ И КОНФИГУРАЦИЯ СЕТИ
----------------------------------------------------------------------------------------
* Внутренний порт приложения: 3000 (прописан в Dockerfile и server.ts)
* Внешний порт (Host Port): 3000 (или любой другой, который вы выберете при пробросе).
* Доменное имя: https://bio.cryteam.ru

Coolify автоматически использует встроенный обратный прокси-сервер (по умолчанию Traefik
или Caddy) для маршрутизации трафика и автоматического выпуска SSL-сертификатов Let's Encrypt.
Вам достаточно указать домен "https://bio.cryteam.ru" в настройках Coolify, и внешний порт 443 (HTTPS)
будет автоматически направлен на внутренний порт контейнера 3000.

----------------------------------------------------------------------------------------
2. СОХРАННОСТЬ ДАННЫХ (PERSISTENT VOLUMES / СХЕМА SQLITE)
----------------------------------------------------------------------------------------
CRY BIOS использует SQLite в качестве базы данных для мгновенного сохранения профилей и аналитики.
База данных, а также загружаемые медиафайлы (музыка, аватарки, фоны) хранятся в директории:
`/app/data`

⚠️ КРИТИЧЕСКИ ВАЖНО: При перезапуске или обновлении Docker-контейнера в Coolify все локальные
файлы внутри контейнера удаляются! 
Чтобы база данных не стиралась на каждом коммите, необходимо смонтировать постоянный том (Volume).

Каталог в контейнере для монтирования: `/app/data`

В docker-compose.yml это уже настроено в виде именованного тома:
------------------------------------------
  volumes:
    - cry_bios_data:/app/data
------------------------------------------

Или в самом GUI интерфейсе Coolify во вкладке "Storages":
  * Тип: Local Volume
  * Имя (Volume Name): cry_bios_data
  * Путь в контейнере (Destination Path): /app/data

----------------------------------------------------------------------------------------
3. ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (ENVIRONMENT VARIABLES)
----------------------------------------------------------------------------------------
Внесите следующие настройки в раздел "Environment Variables" проекта в Coolify:

* NODE_ENV=production
  (Переводит веб-сервер и Vite на сверхбыстрый рабочий режим, оптимизируя загрузку страниц био)

* PORT=3000
  (Уведомляет Docker и веб-сервер, на каком порту вести прослушивание)

* APP_URL=https://bio.cryteam.ru
  (Ваш рабочий адрес для корректного составления реферальных ссылок внутри дашборда)

* GEMINI_API_KEY=your_optional_gemini_key_here
  (Опционально. Если вы планируете запускать ИИ-помощника для автокомпиляции текстов био)

----------------------------------------------------------------------------------------
4. НАСТРОЙКА ДОМЕНА И СУБДОМЕНОВ (bio.cryteam.ru)
----------------------------------------------------------------------------------------
CRY BIOS поддерживает автоматическое перенаправление со вторых уровней доменов.
Если пользователь переходит по адресу `alex.bio.cryteam.ru`, система автоматически считает
и покажет био-страницу пользователя "alex"!

Чтобы это работало на полную мощность:
1. В вашем DNS-редакторе (например Cloudflare) добавьте две записи:
   * A-запись: `bio.cryteam.ru` -> указывает на IP вашего VPS-сервера.
   * Wildcard-запись (А-запись): `*.bio.cryteam.ru` -> указывает на тот же IP.
2. В поле "Domains" настроек приложения в Coolify введите:
   https://bio.cryteam.ru, https://*.bio.cryteam.ru
3. Coolify автоматически организует Let's Encrypt SSL-сертификаты для всех поддоменов,
   обеспечивая бесперебойный доступ пользователей к своим ссылкам!

----------------------------------------------------------------------------------------
5. ПОШАГОВЫЙ ЗАПУСК ЧЕРЕЗ COOLIFY (ДВА ВАРИАНТА)
----------------------------------------------------------------------------------------

ВАРИАНТ А: С Помощью Docker Compose (Самый надежный и простой)
1. В личном кабинете Coolify выберите: `+ New Resource` -> `Service` / `Docker Compose`.
2. Скопируйте и вставьте содержимое файла `docker-compose.yml` из корня проекта.
3. В поле настроек домена укажите: `https://bio.cryteam.ru` (и опционально через запятую `https://*.bio.cryteam.ru`).
4. Нажмите `Save` и затем кнопкой `Deploy` запустите сборку. СУБД SQLite автоматически инициализируется.

ВАРИАНТ Б: Прямой импорт из GitHub (Vite / Node Build Pack)
1. Свяжите ваш GitHub аккаунт с Coolify.
2. Выберите репозиторий с проектом CRY BIOS и ветку `main`.
3. Coolify автоматически обнаружит `Dockerfile`. Оставьте build pack как "Dockerfile".
4. Во вкладке `Storages` добавьте строчку монтирования: имя_тома:/app/data.
5. Нажмите `Deploy`.

----------------------------------------------------------------------------------------
6. CLI И ПРОВЕРКА СОСТОЯНИЯ КОНТЕЙНЕРА
----------------------------------------------------------------------------------------
Для проверки процессов введите в терминал вашего арендованного VPS:

* Статус контейнеров:
  $ docker ps | grep "cry_bios"

* Просмотр логов в реальном времени (отслеживание посещений, авторизаций):
  $ docker logs -f cry_bios_app --tail 200

* Проверка размера и наличия файлов базы данных SQLite:
  $ docker exec -it cry_bios_app ls -lh /app/data
